## `01` — Sobre mim

Olá! Sou **Alexander Brasil**, com foco nas áreas de **Engenharia de Dados** e **Análise de Dados**.

Meu interesse profissional está no ecossistema de dados, envolvendo consulta e transformação de informações, organização de pipelines, ambientes de armazenamento e análise para apoiar a geração de insights.

Tenho interesse em tecnologias e práticas que ajudam a construir soluções de dados organizadas, confiáveis e sustentáveis.

- **Data Engineering:** transformação de dados, pipelines e Data Warehousing.
- **Data Analytics:** SQL, análise de informações, BI e indicadores.
- **Data Transformation:** Python, SQL e dbt.
- **Infraestrutura e colaboração:** Docker, Git e CI/CD.
- **Governança:** organização, qualidade e confiabilidade dos dados.

> Meu objetivo é unir engenharia e análise para construir soluções de dados bem estruturadas.
